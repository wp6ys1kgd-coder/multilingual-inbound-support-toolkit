# 多言語インバウンド対応ツールセット

小売店、宿泊施設、観光案内所、レンタルサービスなどで使える、マクロなしの汎用受付ツールです。日本語、英語、繁体字中国語、韓国語に対応しています。

## 収録ファイル

- `多言語インバウンド対応ツール.xlsx` - 受付記録、定型文検索、サンプルデータ
- `スタッフ向けマニュアル.pdf` - 導入方法、日常操作、四言語の案内例
- `店舗掲示用_多言語案内.pptx` - 編集・印刷できる4枚の店舗掲示
- `sample_data/受付サンプル.csv` - Excelへの貼り付け練習用データ
- `HANDOFF.md` - 納品内容、テスト結果、制限、販売時の注意
- `CHANGELOG.md` - 更新履歴

## すぐに使う

1. `多言語インバウンド対応ツール.xlsx` をExcelで開きます。
2. `受付一覧` シートのサンプル行を削除し、5行目から受付情報を入力します。
3. `案内表示` シートで用件と言語を選ぶと、案内文を表示できます。
4. 店舗独自の文言は `定型文` シートで編集します。
5. 掲示物はPowerPointで文言を確認し、必要なスライドを印刷します。

## 対応環境

- Microsoft Excel 2019以降またはMicrosoft 365
- Microsoft PowerPoint 2019以降またはMicrosoft 365
- PDFを閲覧・印刷できるアプリ

ExcelファイルはVBA、ActiveX、外部データ接続を使用していません。数式は `IFERROR`、`VLOOKUP`、`MATCH` のみを使っています。

## データの扱い

同梱データはすべて架空です。利用開始前にサンプル行を削除してください。実際の氏名、予約番号、対応メモを入力する場合は、保存先、アクセス権、保管期間を店舗側で決めてください。本ツールは暗号化、権限管理、自動バックアップを提供しません。

## カスタマイズ

- 店舗名や会社名は収録していません。必要な場合だけ購入者自身で追記してください。
- 定型文は現場のルールと翻訳責任者の確認後に変更してください。
- PowerPointはロゴなし、16:9、編集可能なテキストで作成しています。

## 免責

翻訳文は一般的な接客用途の例です。法的説明、契約条件、医療、安全、災害対応には、専門家または正式な翻訳者が確認した文言を使用してください。
